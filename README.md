# Data Pipeline com Integração via Telegram
Este projeto demonstra a construção de um pipeline de dados automatizado com notificações via Telegram, ideal para monitorar processos e gerar alertas em tempo real. Ele foi desenvolvido utilizando Python e AWS e pode ser adaptado para diversos tipos de rotinas automatizadas.

📌 Objetivo
Automatizar um fluxo de dados (ETL) com envio de mensagens para um grupo ou usuário no Telegram, permitindo:
* Monitoramento de execução de rotinas;
* Comunicação de erros ou sucesso de processos;
* Agilidade na supervisão de pipelines.

🧰 Tecnologias Utilizadas
* Python (Jupyter Notebook)
* requests – Comunicação com a API do Telegram
* time, datetime, os – Automação e controle de fluxo
* AWS - armazenamento, automação e processamento dos dados

📁 Estrutura do Projeto
├── pipeline_telegram.ipynb    # Notebook com o pipeline e integração com Telegram

├── README.md                  # Este arquivo

⚙️ Funcionalidades
* Execução simulada de um pipeline de dados
* Tratamento de dados e controle de erros
* Envio de mensagens automáticas para o Telegram em diferentes etapas do processo
